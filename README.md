# Personal Portfolio Website

Welcome to my personal portfolio website! This project showcases my academic journey, technical skills, projects, certifications, and contact information in a clean and modern web interface.

## Features

- Home section with personal introduction
- About Me section
- Technical Skills
- Projects showcase
- Certifications
- Education
- Contact section
-  GitHub and LinkedIn links
- Responsive and modern design

## Technologies Used

- HTML5
- CSS3
